# 會議看板重新設計 — 功能保留清單

> 目的：透過 Chrome extension content script 注入 CSS 重新設計 `本日會議` 頁面的視覺風格，
> 外觀可以改，但以下功能（DOM 結構、id/name/class、JS 綁定）**不可更動**，只能調整樣式。
>
> 對應原始頁面：`本日會議_files/本日會議.html`

## 1. 設定 Modal（`#options`）

點擊右上角 ⚙️（`.options button`，`data-toggle="modal" data-target="#options"`）開啟的「表單顯示選項」視窗。

| 功能 | selector / id | 備註 |
|---|---|---|
| 開啟設定視窗 | `.options button` | 觸發 modal，`data-toggle`/`data-target` 不可動 |
| 顯示開過之會議 | `#Display`（name="Display"） | value: 0=不顯示, 1=顯示 |
| 報表呈現類型 | `#Type`（name="Type"） | value: 0=本日, 1=七日, 2=三十日 |
| 地區 | `#Region`（name="Region"） | 林森/昆陽/臺北區/北區/中區/南區/高屏區/東區/衛生局 |
| 滾動速度 | `#ScrollSpeed`（name="ScrollSpeed"） | UI 保留在側邊選單，語意不變（0=不滾動, 1~5）。但**滾動的實際執行者已換成 extension**：redesign.js 的 `startAutoScroll()` 讀取這顆欄位的值來驅動滾動（原站 Meeting.js 的滾動邏輯已被 style.css 讓 `.tbl-content` 不再是滾動容器而失效）。選擇後仍需按「確認選擇」送出表單、頁面 reload 生效 |
| 主持人 checkbox | `#Host`（name="Host"） | pretty-checkbox 元件 |
| 承辦人 checkbox | `#User`（name="User"） | pretty-checkbox 元件 |
| 承辦單位 checkbox | `#Unit`（name="Unit"） | pretty-checkbox 元件 |
| 視訊連線 checkbox | `#Video`（name="Video"） | pretty-checkbox 元件 |
| 事務準備 checkbox | `#Preparing`（name="Preparing"） | pretty-checkbox 元件 |
| 備註 checkbox | `#Note`（name="Note"） | pretty-checkbox 元件 |
| 送出設定 | `#btn-select-host` | `<form action="/Meeting/Meeting" method="post">`，含 CSRF token `__RequestVerificationToken`，絕對不可動 |

## 2. 主表格（`.tbl-header` + `.tbl-content`）

表頭與內容是兩張獨立 `<table>`（固定表頭捲動內容手法），欄寬用 inline `style="width:xx%"` 對齊。

| 欄位 | 是否必顯 | 備註 |
|---|---|---|
| 會議時間 | **強制必顯** | 不受設定 modal 控制 |
| 會議名稱 | **強制必顯** | 不受設定 modal 控制 |
| 會議地點 | **強制必顯** | 不受設定 modal 控制 |
| 主持人 | 可隱藏 | 由 `#Host` 控制 |
| 承辦單位 | 可隱藏 | 由 `#Unit` 控制 |
| 承辦人 | 可隱藏 | 由 `#User` 控制 |
| 備註 | 可隱藏 | 由 `#Note` 控制，內容可能為長文字（如 Webex 連線資訊），需保留 `white-space: pre-wrap` 多行顯示 |
| 視訊連線 | 可隱藏 | 由 `#Video` 控制，`.btn-video` 按鈕 `onclick="openVideoModal(id)"` 呼叫 `Meeting.js` 全域函式，不可更動綁定 |

其他保留事項：
- 斑馬紋列（`.tbl-content tr:nth-child(2n+1)`）可換配色，但需保留列與列的視覺區隔
- 表頭欄寬需與內容欄寬同步，避免跑版

## 3. 頂部標題列（`.title-bar`）

- 署徽（`.logo`）、中英文名稱（`.logo-title`）、「本日會議」標題（`.tbl-title`）、日期（`.today`，`position: fixed`）
- 內容皆由後端渲染，樣式可換但 DOM 結構/資料來源不動

## 4. 視訊會議 Modal（`#videoRoomSelect`）

- 點擊 `.btn-video` 按鈕開啟，內容由 `Meeting.js` 動態填入 `#video-room-select-div`
- Modal 結構與 id 不可更動

## 5. content.js 語音搜尋機制（extension 自身功能）

content.js 搜尋時會對表格列動態加 class，新設計的 style.css 必須與之相容：

| class | 用途 | style.css 的處理 |
|---|---|---|
| `.meeting-hidden` | 隱藏不符合搜尋的列 | 已補 `display:none !important`（權重需贏過卡片的 `display:flex`） |
| `.meeting-odd` / `.meeting-even` | 搜尋命中列的斑馬紋高亮 | 已改為亮紫玻璃高亮（原本的白底在深色主題不可讀） |
| `mark.highlight-match` | 關鍵字螢光筆 | 黃底黑字在深色主題仍可讀，未動 |

另外：redesign.js 會移除會議地點欄的括號註記（如「(不開放外機關借用)」），
語音搜尋這些註記文字會查不到；搜尋地點名稱本身不受影響。
